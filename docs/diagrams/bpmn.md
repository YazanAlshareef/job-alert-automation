# Daily alert process (BPMN)

The daily alert as BPMN 2.0: fetch, dedupe, filter, score, rank, send if there are matches, save the seen list.

File: [daily-alert.bpmn](daily-alert.bpmn)

To open it, go to https://demo.bpmn.io, choose Open, and pick the file. The file is read in the browser.

Sources: [main.py](../../main.py), [daily.yml](../../.github/workflows/daily.yml)
